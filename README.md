ADVANCED MOTION SYSTEM

Use a consistent motion language across the website.

1. Slow Image Float

Property images subtly move vertically by 4–10px.

2. Scroll Parallax

Background images move at approximately 0.8x scroll speed.

3. Image Pop

Images smoothly scale from approximately 96% → 100%.

4. Card Lift

Cards move upward 4–8px on hover.

5. Soft Glow

Important CTA elements get a subtle colored glow.

6. Magnetic Buttons

Desktop CTA buttons can slightly follow the cursor.

Keep movement minimal.

7. Text Reveal

Headlines can reveal line-by-line as they enter the viewport.

8. Mask Reveal

Large property photos reveal through rounded masks.

9. Horizontal Scroll

Reel sections respond naturally to drag and wheel movement.

10. Slow Video Transitions

Videos should fade/scale subtly when becoming active.

IMAGE "POP" EFFECT

This is especially important.

Whenever a major property image enters the viewport:

Start at approximately 95% scale.

Slightly blur the image.

Reveal using a rounded mask.

Slowly sharpen.

Scale to 100%.

Add subtle parallax.

Reveal metadata on top.

The final result should feel like the image is coming alive from the page.

Do not make it happen too quickly.
